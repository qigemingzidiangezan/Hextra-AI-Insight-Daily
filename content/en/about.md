#### My Cool Projects 🛠️

*   **[Open Source Contribution / AIClient-2-API](https://github.com/justlovemaki/AIClient-2-API)**: This bad boy, **AIClient-2-API**, is a robust API proxy service. It brilliantly packages client-only large model capabilities (think Gemini CLI, Antigravity, Qwen Code, Kiro, and more!) into a local OpenAI-compatible interface. Plus, it's packed with features like account pool management, smart polling, automatic failover, and system prompt management. Pretty neat, right?
*   **[Open Source Contribution / OpenClaw-Docker-CN-IM](https://github.com/justlovemaki/OpenClaw-Docker-CN-IM)**: Then there's **OpenClaw-Docker-CN-IM**, a Docker image for OpenClaw's integrated Chinese IM plugins. This gem comes pre-installed and configured with plugins for all the major Chinese IM platforms—we're talking Feishu, DingTalk, QQ Robot, WeChat Work, and more! It's super quick to deploy, giving you a multi-platform AI bot gateway in a flash.
