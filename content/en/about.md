*   **[Open-source Contribution/AIClient-2-API](https://github.com/justlovemaki/AIClient-2-API)**:
    *   AIClient-2-API is a robust API proxy service. It wraps client-only large model capabilities like Gemini CLI, Antigravity, Qwen Code, and Kiro into local OpenAI-compatible interfaces. Plus, it rocks features like account pool management, intelligent load balancing, automatic failover, and system prompt management.
*   **[Open-source Contribution/OpenClaw-Docker-CN-IM](https://github.com/justlovemaki/OpenClaw-Docker-CN-IM)**:
    *   OpenClaw-Docker-CN-IM is a Docker image that integrates Chinese IM plugins. It comes pre-installed and configured with plugins for major Chinese IM platforms like Feishu, DingTalk, QQ Bot, and WeChat Work. This makes it super fast to deploy a multi-platform AI bot gateway.
