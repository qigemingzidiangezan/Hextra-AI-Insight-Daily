#### 🚀 Featured Work

*   **[Open Source Contribution/AIClient-2-API](https://github.com/justlovemaki/AIClient-2-API)**:
    AIClient-2-API is a seriously powerful API proxy service. It neatly wraps up client-only large language model (LLM) capabilities (think Gemini CLI, Antigravity, Qwen Code, Kiro, and more) into a local, OpenAI-compatible interface. Plus, it's packed with cool features like account pool management, smart polling, automatic failover, and easy system prompt management. Pretty neat, right?
*   **[Open Source Contribution/OpenClaw-Docker-CN-IM](https://github.com/justlovemaki/OpenClaw-Docker-CN-IM)**:
    OpenClaw-Docker-CN-IM is your go-to integrated Docker image for Chinese IM plugins. It comes pre-loaded and perfectly configured with plugins for all the big-name Chinese IM platforms – like Feishu, DingTalk, QQ Bot, and WeChat Work. This baby lets you swiftly deploy a multi-platform AI chatbot gateway. Super convenient!
