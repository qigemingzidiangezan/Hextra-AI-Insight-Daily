#### ⭐ Showcase

*   **[Open Source Contribution/AIClient-2-API](https://github.com/justlovemaki/AIClient-2-API)**:
    *   **AIClient-2-API** is a kickass API proxy service that wraps up client-only large language model (LLM) capabilities (think Gemini CLI, Antigravity, Qwen Code, Kiro, and more!) into a local OpenAI-compatible interface. It also handles account pool management, smart polling, automatic failover, and system prompt management. Pretty neat, huh?
*   **[Open Source Contribution/OpenClaw-Docker-CN-IM](https://github.com/justlovemaki/OpenClaw-Docker-CN-IM)**:
    *   **OpenClaw-Docker-CN-IM** is an all-in-one Docker image for OpenClaw Chinese IM plugins. It comes pre-loaded and configured with all the popular Chinese IM platform plugins like Feishu, DingTalk, QQ Bot, and WeChat Work, making it a breeze to deploy a multi-platform AI bot gateway.
*   Find even more project details on my [GitHub](https://github.com/justlovemaki).
